# Đoàn E-learning MVP

Web MVP kết nối trực tiếp với Supabase project `noafrcwfuddxclwuhfsm`.

## Chạy
Mở `index.html` qua một static host (Cloudflare Pages, Vercel static, GitHub Pages có thể dùng).

## Luồng đã có
- Đăng ký / đăng nhập Supabase Auth
- Chọn Đoàn cơ sở / Chi đoàn
- Học khóa học, đánh dấu hoàn thành
- Kỳ thi có thời gian, giới hạn lượt
- Chấm điểm phía database bằng RPC
- Lịch sử học tập / kết quả thi
- Trang tài khoản
- Trang quản trị cơ bản: website, tổ chức, danh sách đoàn viên

## Lưu ý
Không đưa service-role key vào frontend. File chỉ chứa publishable key.
